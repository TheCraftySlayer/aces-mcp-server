# Database scripts

| File | What it is |
|---|---|
| `current/ai_api.sql` | The `ai_api` schema as it is in the database: every procedure, the `tool_log` columns and every permission on the schema. Generated by `export_ai_api.py`; this is what to read to check what each procedure the data tools call does. |
| `export_ai_api.py` | Writes `current/ai_api.sql`. Run it after any `ai_api` change (instructions at the top of the file) and commit the result. |
| `51_` to `54_` | Changes applied to the database, in order. They're kept as the record of what was run and why. |

Scripts numbered below 51 were applied before this folder existed. Their definitions are in
the database snapshot in the ACES forecasting repo (`ACES_DotNet_Source`, `database/`), and
`current/ai_api.sql` shows the result of all of them for `ai_api`. The "to undo, rerun 48"
notes in 51 and 52 refer to that repo.

53 and 54 also create the `dbo` season tables and `dbo.aces_season_refresh`, which belong to
the forecasting app. They stay here because 54 defines `ai_api.season_outlook`, which the
`ACES_Season_Outlook` tool calls.

None of this folder goes into the container image (`.dockerignore` is an allowlist).
